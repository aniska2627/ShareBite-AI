# 🍃 ShareBite AI — Smart Food Redistribution Network

**An AI-assisted food redistribution prototype built with Python and Tkinter.**

ShareBite AI aims to reduce food waste by connecting food donors with NGOs and volunteers. The application demonstrates donation management, recipient matching, delivery tracking, and impact analytics.

## 🎯 Problem Statement

Restaurants, college canteens, bakeries, and supermarkets may have surplus food while nearby communities need food assistance. Efficiently matching available food with suitable recipients can help reduce avoidable food waste.

## 💡 Proposed Solution

ShareBite AI provides a desktop application for managing food donations, recommending suitable NGOs, tracking delivery progress, and measuring redistribution activity.

## ✨ Features

- **Dashboard:** Overview of donations, available food, ongoing deliveries, and impact.
- **Food Donation Management:** Create, search, filter, and update donations.
- **SmartMatch Engine:** Rule-based scoring to recommend NGOs using location, category compatibility, capacity, pickup availability, and storage requirements.
- **NGO Directory:** View sample organizations and their capabilities.
- **Delivery Tracking:** Assign volunteers and track pickup and delivery statuses.
- **Impact Analytics:** Calculate delivered food quantities and estimated meal portions.
- **Local Data Storage:** Save application data in JSON.
- **Data Export:** Export records to a JSON file.

## 🚀 Getting Started

### Prerequisites

Install Python 3.10 or later. Tkinter should be available with your Python installation.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ShareBite-AI.git
   ```

2. Open the project directory:

   ```bash
   cd ShareBite-AI
   ```

3. Run the application:

   ```bash
   python sharebite_ai.py
   ```

Alternatively, open `sharebite_ai.py` in Python IDLE and press **F5**.

## 🧠 SmartMatch Algorithm

The matching engine calculates a score out of 100 based on:

| Matching factor | Maximum points |
|---|---:|
| Location compatibility | 35 |
| Food category compatibility | 25 |
| NGO capacity | 20 |
| Pickup availability | 10 |
| Storage compatibility | 10 |
| **Total** | **100** |

The scores are transparent, rule-based recommendations. They are not generated by a trained machine-learning model.

## 📊 Impact Calculation

Estimated meal portions are calculated using:

`Estimated portions = Delivered food in kg × 4`

The factor of four is a demonstration assumption and should be adjusted using a justified methodology for real-world deployment. It is not a verified measure of nutritional impact.

## 🗂️ Data Storage

Application records are saved locally in `sharebite_data.json`. The application creates sample data on its first run.

The included NGOs, donors, and volunteers are fictional demonstration records. This prototype does not provide cloud synchronization, online authentication, or live maps.

## 🔐 Limitations

- Desktop application rather than a browser-based website.
- Local JSON storage rather than a shared database.
- Demo role selection rather than production authentication and authorization.
- Rule-based NGO recommendations rather than an LLM or trained AI model.
- No live notifications or verified external NGO directory.

Food safety, allergen information, and safe-use deadlines must be checked by responsible people.
